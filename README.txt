LEYROS CONNECTED FRONTEND

Pages:
- index.html       Home page
- collection.html  Olfactory Library / collection
- product.html     Nuit Dorée product detail
- atelier.html     Maison / Atelier page

Navigation has been connected between the four HTML files.

How to preview locally:
1. Keep all four HTML files in the same folder.
2. Open index.html in a browser.

Netlify:
- Drag the entire leyros-connected folder into Netlify Drop / deploy area.

Vercel:
- Upload/push the folder as a static project. index.html is the entry page.

Important:
- The site uses external Google Fonts, Tailwind CDN, external image URLs, and a remote video URL, so internet access is required for all assets to display.
- This is frontend-only. Cart, search, checkout, login, database, and payment functionality are not implemented unless already present as client-side demo behavior.
